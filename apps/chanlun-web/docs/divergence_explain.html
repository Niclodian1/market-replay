趋势背驰 vs 盘整背驰 — 一图看懂差别

两者都是「MACD 面积衰竭」，但结构前提完全不同：趋势背驰需要至少两个同向中枢（下跌/上涨趋势成立），盘整背驰只需要一个中枢。你系统里这两个信号不精确的感觉，多半来自它们经常在同一根K线附近先后触发——因为判据相似、语境不同。

① 趋势背驰（第24课）→ 一买的依据

关键点：必须有中枢链（B 比 A 更低，下跌趋势才成立），且 C 段要创出链上新低。比较对象是「进入 B 的 A 段」vs「离开 B 的 C 段」。你系统里 type=1 的买点就是它（A段=进入段口径，已定稿）。

② 盘整背驰（第25课）→ 独立信号「盘整背驰买」，不是一买

关键点：只有一个中枢也能触发。C 段跌破 DD 才算「真离开」（在中枢区间内往返只是震荡，不判）。你系统里 k=「盘整背驰买」就是它，独立于三类买卖点单独统计。

③ 并排对照

趋势背驰（→一买）盘整背驰（→盘整背驰买）
中枢数量≥2 个同向中枢（趋势成立）1 个即可
C 段条件创出中枢链新低（低于前中枢 DD）跌破本中枢 DD 即可
A 段相同：进入当前中枢的同向段（你的系统已定稿此口径）
力度比较相同：area(C) < θ×area(A)，θ=0.9，MACD 绿/红柱面积
理论预期趋势结束 → 反转（走势必完美）回中枢继续震荡（第25课震荡操作）
回测表现(BTC)一买是核心入场信号4H 强(PF 11.2) / 1H 噪声(PF 0.51)

④ 为什么你会觉得系统里「不精确」— 三个真实的模糊地带

模糊点说明系统的处理
A 段取哪段原文没明说是「进入最后一个中枢的段」还是「整条趋势最猛的段」两种都实现过，回测定稿为进入段（strongest 口径已删）
「面积」怎么算MACD 柱面积只是力度的代理，原文说的力度还包括斜率/成交量等只用柱面积 × θ=0.9 阈值；规范 §15 标注为 L2 级代理决策
两个信号同时出现单中枢破位时若恰好前面还有个更低中枢，趋势背驰和盘整背驰可能几乎同时满足各自独立判定、独立发出（k 不同），不做互斥——这是设计选择，规范 §12 有记录
