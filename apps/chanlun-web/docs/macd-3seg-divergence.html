1. 状态机定义

记 $h_i$ 为第 $i$ 根收盘后的 MACD 柱（12/26/9，EMA 递推 adjust=False，前缀稳定）。

全部判断只读 index ≤ i 的数据。

1.1 段的在线划分

情形条件（第 i 根收盘时）处理
变色$\operatorname{sign}(h_i) \ne$ 当前段颜色当前段结束，新段开始（原文“出现相反颜色的柱”）
触零$\lvert h_i\rvert \le 0.10 \times \max\lvert h\rvert_{\text{本段已出现}}$，且本段峰值不是噪声级记为“谷底”，继续跟踪；后续若出现更低的柱则谷底后移
确认拆段谷底之后新柱群峰值 $\ge 0.30 \times$ 谷底前的段峰值旧段截止到谷底，新段从谷底下一根开始（原文“非常接近出现”）
小回撤并回谷底后新柱群始终 < 30% 前段峰值不拆段，仍属同一段
噪声段段完成时峰值 $< 0.20 \times \max\lvert h\rvert_{\text{近100根}}$只作隔断，不参与 S1/S2 比较

“非常接近零轴”拆成触零和确认两步，因为只看某一根是否触零，会把段内的小回撤也误切开。

例如 2023-04-30 柱值 −31，是前段峰值 −415 的 7.5%，但随后只反弹到 −90，所以并回原段。

2024-03-31 柱值 −109，是前段峰值 −1304 的 8.4%，随后新柱群走到 −648，所以确认拆段。

1.2 入场（以底背离为例，顶背离镜像）

S3 为包含 $T-1$ 的当前段，S1、S2 为它之前最近两个同色、非噪声的已完成段。

三个段的价格极值都取影线：底背离取 low，顶背离取 high。S3 的价格包含触发当根。

$$L_1 > L_2 > L_3,\qquad |H_1| > |H_2| > |H_3|,\qquad h_{T-1}<0,\ h_T>h_{T-1}$$
  • 缩短须超过 2%：$|H_{k+1}| < 0.98\,|H_k|$。原文认可的最小缩短是 52.8→51.5，即 2.5%。
  • S3 柱峰值须 $\ge 5\%\,|H_2|$，用来排除只有 1 根噪声小柱的“伪第三段”。
  • 满足条件时，在 $T$ 收盘按 close[T] 入场；当根柱子直接翻绿也算。

1.3 止损与二次入场

  1. 硬止损：S3 的影线极值 $L_3$/$P_3$（含入场当根）。盘中触及即出场，优先于次日检查。
  2. 次日动能止损：$T+1$ 收盘时，底背离若 $h_{T+1} \le h_T$ 则止损；顶背离若 $h_{T+1} \ge h_T$ 则止损。
  3. 二次入场：止损后，S3 须在止损根之后严格创出新的影线极值，且柱峰值仍满足缩短条件，再次出现缩短时重新入场。
  4. 噪声小柱续段：入场当根变色、次日又变回原色，且相反色柱是噪声级、长度不超过 3 根时，S3 继续延续。这对应 2023-06-06 的 +2.4 绿柱。

1.4 因果性校验（pytest）

  • test_macd_prefix_stable：截断数据和全量数据的 MACD 逐点相等。
  • test_truncation_equivalence_1d：在每个事件当根 $T$ 截断后，$T$ 及以前的事件和全量运行逐字段一致。
  • test_future_poison_does_not_leak：把 $T$ 之后的 K 线换成随机噪声，$T$ 及以前的事件不变。
  • 另外两项是随机截断点测试和 4H 抽样截断测试。
