# 告警指标计算逻辑

所有告警每 5 分钟检查一次，检测最新一根K线是否产生入场信号（与回测入场信号逻辑一致）。
信号值：`1` = 买入方向，`-1` = 卖出方向，`0` = 无信号。

---

## 1. 价格突破（price_above / price_below）

### 描述
实时价格突破用户设定的阈值时触发。与K线信号无关，直接比较当前报价。

### 计算逻辑
- **price_above**：当前价格 > 阈值 → 触发
- **price_below**：当前价格 < 阈值 → 触发

### 参数
- `threshold`：目标价格（必填）

---

## 2. 均线交叉（ma_cross）

### 描述
检测 MA20 与 MA60 的金叉（快线上穿慢线）或死叉（快线下穿慢线）。

### 计算逻辑

1. 计算 SMA(20) 和 SMA(60)：

```
SMA(N) = (C[i] + C[i-1] + ... + C[i-N+1]) / N
```

2. 比较相邻两根K线的均线差值：

```
prev_diff = SMA20[i-1] - SMA60[i-1]
curr_diff = SMA20[i] - SMA60[i]
```

3. 判断交叉：
   - **金叉（买入）**：`prev_diff <= 0` 且 `curr_diff > 0`
   - **死叉（卖出）**：`prev_diff >= 0` 且 `curr_diff < 0`

### 参数
无（固定 MA20 / MA60）

---

## 3. RSI 超买超卖（rsi）

### 描述
RSI 从正常区域突破进入超买或超卖区域时触发。

### 计算逻辑

1. 计算 RSI(14)：

```
变动 = C[i] - C[i-1]
涨幅 = max(变动, 0)
跌幅 = max(-变动, 0)

初始平均涨幅 = SUM(前14根涨幅) / 14
初始平均跌幅 = SUM(前14根跌幅) / 14

后续采用 Wilder 平滑：
avg_gain[i] = (avg_gain[i-1] × 13 + gain[i]) / 14
avg_loss[i] = (avg_loss[i-1] × 13 + loss[i]) / 14

RSI = 100 - 100 / (1 + avg_gain / avg_loss)
```

2. 判断信号：
   - **超卖反弹（买入）**：`RSI[i-1] >= 超卖线` 且 `RSI[i] < 超卖线`
   - **超买回落（卖出）**：`RSI[i-1] <= 超买线` 且 `RSI[i] > 超买线`

### 参数
- `threshold`：超买阈值（默认 70），超卖阈值自动取 `100 - threshold`（默认 30）

---

## 4. MACD 交叉（macd）

### 描述
MACD 线与信号线发生交叉时触发。

### 计算逻辑

1. 计算 MACD 三线：

```
EMA(N) 初始值 = SMA(N)
EMA(N)[i] = C[i] × k + EMA(N)[i-1] × (1 - k)，其中 k = 2 / (N + 1)

MACD线 = EMA(12) - EMA(26)
信号线 = EMA(9, MACD线)
柱状图 = MACD线 - 信号线
```

2. 比较相邻两根K线：

```
prev = MACD线[i-1] - 信号线[i-1]
curr = MACD线[i] - 信号线[i]
```

3. 判断交叉：
   - **MACD 金叉（买入）**：`prev <= 0` 且 `curr > 0`
   - **MACD 死叉（卖出）**：`prev >= 0` 且 `curr < 0`

### 参数
无（固定 EMA12 / EMA26 / Signal9）

---

## 5. 价格突破均线（ma_breakout）

### 描述
收盘价从均线的一侧穿越到另一侧时触发。

### 计算逻辑

1. 计算 SMA(N)：

```
SMA(N)[i] = (C[i] + C[i-1] + ... + C[i-N+1]) / N
```

2. 比较前后两根K线收盘价与均线的位置关系：

```
prev_above = C[i-1] > SMA[i-1]
curr_above = C[i] > SMA[i]
```

3. 判断突破：
   - **上穿均线（买入）**：`prev_above = false` 且 `curr_above = true`
   - **下穿均线（卖出）**：`prev_above = true` 且 `curr_above = false`

### 参数
- `ma_period`：均线周期（默认 20）

---

## 6. MACD 背离（macd_divergence）

### 描述
价格与 MACD 柱状图走势背离时触发，属于趋势反转信号。

### 计算逻辑

1. 计算 MACD 柱状图（同上）。

2. 寻找价格的局部极值点（lookback = 5）：

```
对于位置 i，取窗口 [i-5, i+5] 共 11 根K线：
- 若 C[i] = max(窗口) → 标记为波峰
- 若 C[i] = min(窗口) → 标记为波谷
```

3. 比较相邻两个同类极值点：

   - **多头背离（买入）**：价格创新低（`C[当前谷] < C[前一谷]`）但柱状图抬高（`Hist[当前谷] > Hist[前一谷]`）→ 下一根K线产生买入信号

   - **空头背离（卖出）**：价格创新高（`C[当前峰] > C[前一峰]`）但柱状图降低（`Hist[当前峰] < Hist[前一峰]`）→ 下一根K线产生卖出信号

### 参数
无（固定 lookback = 5）

---

## 7. 布林带触及（bollinger）

### 描述
收盘价突破布林带上轨或下轨时触发。

### 计算逻辑

1. 计算布林带三轨：

```
中轨 = SMA(20)
标准差 = sqrt(SUM((C[j] - 中轨)² for j in 窗口) / 20)
上轨 = 中轨 + 2 × 标准差
下轨 = 中轨 - 2 × 标准差
```

2. 判断突破：
   - **跌破下轨（买入）**：`C[i-1] >= 下轨[i-1]` 且 `C[i] < 下轨[i]`
   - **突破上轨（卖出）**：`C[i-1] <= 上轨[i-1]` 且 `C[i] > 上轨[i]`

### 参数
无（固定 period = 20，num_std = 2.0）

---

## 8. 支撑阻力突破（sr_breakout）

### 描述
收盘价突破动态计算的支撑位或阻力位时触发。

### 计算逻辑

1. **寻找局部极值点**（lookback = 5）：

```
对于位置 i，取窗口 [i-5, i+5]：
- 若 High[i] = max(窗口所有 High) → 标记为高点
- 若 Low[i] = min(窗口所有 Low) → 标记为低点
```

2. **聚类形成支撑阻力位**（tolerance = 0.5%）：

```
将所有极值价格排序
相邻价格差 <= 0.5% 时归入同一簇
簇内至少 2 次触及 → 取平均价作为一个 SR 水平
```

3. **滚动窗口避免未来函数**：对每根K线，只用其之前的所有K线计算 SR 水平。

4. **判断突破**：

```
tol = level × 0.5%
```

   - **突破阻力（买入）**：`C[i-1] <= level + tol` 且 `C[i] > level + tol`
   - **跌破支撑（卖出）**：`C[i-1] >= level - tol` 且 `C[i] < level - tol`

### 参数
无（固定 lookback = 5，min_touches = 2，tolerance = 0.5%）

---

## 9a. Pinbar 锤子线（pinbar）

### 描述
检测 Pinbar（锤子线/射击之星），要求影线波动至少占价格的 2%。

### 计算逻辑

分析单根K线的影线与实体比例，并要求影线有足够的绝对波动：

```
实体 = |C - O|
上影线 = H - max(O, C)
下影线 = min(O, C) - L
```

- **看涨 Pinbar / 锤子线（买入）**：`下影线 >= 实体 × 2` 且 `上影线 < 实体` 且 `下影线 / L >= 2%`
- **看跌 Pinbar / 射击之星（卖出）**：`上影线 >= 实体 × 2` 且 `下影线 < 实体` 且 `上影线 / H >= 2%`

### 参数
- `ratio`：影线与实体的最小比例，默认 2.0
- `min_wick_pct`：影线占价格的最小百分比，默认 0.02（2%）

---

## 9b. 吞没形态（engulfing）

### 描述
检测吞没形态，要求前一根K线有至少 2% 的波动，且后一根K线实体收回跌/涨幅。

### 计算逻辑

分析相邻两根K线：

- **看涨吞没（买入）**：前一根为阴线且跌幅 `(O-C)/O >= 2%`，当前为阳线且收盘价 `C >= 前一根开盘价`（实体收回跌幅）
- **看跌吞没（卖出）**：前一根为阳线且涨幅 `(C-O)/O >= 2%`，当前为阴线且收盘价 `C <= 前一根开盘价`（实体收回涨幅）

### 参数
- `min_move_pct`：前一根K线的最小波动百分比，默认 0.02（2%）

---

## 10. W底双底（w_bottom）

### 描述
检测 W底（双底）与 M顶（双顶）反转形态。W底：价格在相近支撑位形成两个低点，中间有反弹，第二个低点确认后产生买入信号。M顶为此形态的镜像（卖出）。

### 计算逻辑

1. **寻找摆动低点与摆动高点**（左右各 `swing_window = 30` 根K线）：

```
Low[i] < 左右30根K线所有 Low → 标记为摆动低点
High[i] > 左右30根K线所有 High → 标记为摆动高点
```

2. **计算支撑位**（保守取值，过滤影线噪音）：

```
支撑位 = min(O, C)  即实体下沿
```

3. **W底匹配条件**：

```
后低与前低间距 >= 60 根K线
|支撑位_j - 支撑位_i| / 支撑位_i <= 3%
后低最低价 >= 前低支撑位 × 98.5%（不允许明显下破）
中间最高价反弹幅度 >= 5%（(中间最高 - 支撑位) / 支撑位）
```

4. **M顶匹配条件**（镜像）：

```
后高与前高间距 >= 30 根K线
阻力位 = max(O, C)（实体上沿）
|阻力位_j - 阻力位_i| / 阻力位_i <= 3%
后高最高价 <= 前高阻力位 × 101.5%（不允许明显上破）
中间最低价回调幅度 >= 5%
```

5. **信号标记**：

   - W底确认 → `信号[j] = 1`（在第二个低点触发）
   - M顶确认 → `信号[j] = -1`（在第二个高点触发）

### 参数
- `min_distance`：两低/高点最小间距（K线数），默认 30
- `swing_window`：极值检测窗口，默认 5
- `tolerance_pct`：两支撑/阻力位最大差异，默认 0.03（3%）
- `min_rally_pct`：中间最小反弹/回调幅度，默认 0.05（5%）

---

## 基础指标公式汇总

| 指标 | 公式 |
|------|------|
| SMA(N) | `SUM(C[i-N+1..i]) / N` |
| EMA(N) | 初始 = SMA(N)；后续 `C[i] × k + EMA[i-1] × (1-k)`，`k = 2/(N+1)` |
| RSI(14) | `100 - 100 / (1 + avg_gain / avg_loss)`，Wilder 平滑 |
| MACD线 | `EMA(12) - EMA(26)` |
| 信号线 | `EMA(9, MACD线)` |
| 柱状图 | `MACD线 - 信号线` |
| 布林上轨 | `SMA(20) + 2 × StdDev(20)` |
| 布林下轨 | `SMA(20) - 2 × StdDev(20)` |
