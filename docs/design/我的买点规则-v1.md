# 我的买点规则 v1（MA20 回踩识别）

> 数据来源：`annotations-BTC-1D-manual.json`（72 个人工买点，BTC 日线 2018-04 ~ 2026-08）
> 实现：`apps/chanlun-web/js/13-annotate.js` → `ANN_MYBUY` / `annMyBuyScore()` / `annMyBuyBuild()`
> 复算：`python3 scripts/analysis/mybuy_rules.py && python3 scripts/analysis/build_mybuy_dashboard.py`
> 看板：`apps/chanlun-web/analysis/mybuy.html`

## 1. 从 72 个买点看到的共性

| 观察 | 数字 |
|---|---|
| 收盘价就落在上穿 MA20 的那根 K 线上 | 63 / 72（87.5%） |
| 距某次上穿 ≤1 根 | 68 / 72（94.4%） |
| 距某次上穿 ≤2 根 | 69 / 72（95.8%） |
| 买在「一段下跌或横盘之后」——没有一笔是持续上涨途中追的 | 72 / 72 |
| 买入 K 线是阳线 | 72 / 72 |

**结论：一个动作就够了——「下跌/盘整之后，收盘重新站上 MA20，并且是阳线」。**
差别只在于「这个上穿值不值得做」，而不是「买点长什么样」。

9 个不是「首次上穿」的点（突破后回踩 1~2 根再站上）是这条规则最初漏掉的主要原因，
所以候选窗口从「首次上穿」放宽到「最近 3 根内上穿过」。

## 2. 固化后的算法

```
候选：close > MA20，且最近 3 根内出现过 (前一根 <= MA20 且本根 > MA20)；且 close > open
过滤：close / MA20 - 1 <= 10%
打分：盘整≥5根 +20 / 破下跌趋势线 +20 / 实体≥2% +15 / 放量(vr≥1) +15
      / MACD柱 强于3根前 +10 / close>MA60 +10 / 距MA20 1~3% +10
门槛：≥30 出信号；≥60 A，40~59 B，30~39 C
入场：信号 K 线收盘价     止损：信号 K 线最低价
```

对 72 个手工买点：**精确命中 66，±1 根 68，±2 根 69（95.8%）**；
信号总数 239（约 26 个/年），其中约一半是手工买点（精度 49.4%）。
3 个漏点：2019-12-18（收盘在 MA20 下方 0.01%）、2023-02-26（20 分）、2023-03-01（25 分）。

## 3. 这个算法的能力边界（重要）

把 178 个「首次上穿 + 阳线 + 距均线≤10%」的时点摊开，逐因子比较「我选的 72 个」和「其余 105 个」：

| 因子 | 我选的（中位） | 我没选的（中位） | 单因子 AUC |
|---|---|---|---|
| 盘整时长（连续跌破 MA20 根数） | 6 根 | 3 根 | 0.55 |
| 突破力度（实体%） | 3.82% | 2.89% | 0.61 |
| 收盘距 MA20 | 2.08% | 0.93% | **0.69** |
| 当日量 / 20日均量 | 1.13× | 0.94× | 0.59 |
| 振幅收缩（10根/60根） | 0.82× | 0.94× | 0.65 |
| 量能收缩（10根/60根） | 0.83× | 0.93× | 0.63 |
| 上影线 / 收盘 | 0.76% | 0.78% | 0.52 |
| MA20 斜率（5根 %/根） | −0.14% | −0.08% | 0.53 |

最强单因子 AUC 0.69；把因子加到 20 个、用 GBM 做 5 折交叉验证，AUC 也只从 0.59 涨到 **0.62**。

**所以：这套打分只能做粗筛，不能当自动信号。**
真正区分好坏的是「前面跌了多久、这波是不是第一波回踩、趋势线画在哪」这类看图判断，
7 个数值因子表达不出来。把它定位成**待审清单**才对：算法列出来，人再过一遍。

## 4. 建议保留 / 建议修改

**保留**
- 「收盘站上 MA20 + 阳线」作为唯一候选定义——72 个买点全中。
- 「低点止损」——它同时定义了风险，让所有交易可比（R 倍数）。
- 分级 A/B/C 只作优先级，不做硬过滤——精度换召回是刻意的。

**建议修改**
1. 「距 MA20 1~3% +10」这一条方向不对。数据显示我选的买点离 MA20 **更远**（中位 2.08% vs 0.93%），
   改成「≥1.5% 加分、≥2.5% 再加、>10% 剔除」更贴近实际。
2. 加冷却期（5~10 根）。同一波趋势里算法会连报 2~3 个相邻信号，去重后信号降到 116~160 个，
   总 R 基本不变，可读性明显变好。
3. 别再堆因子了。试过 20 个特征（回撤深度、距前高、ATR、影线、均线挤压……），
   交叉验证 AUC 从 0.59 只涨到 0.62，信息不在这些数值里。

## 5. 已知偏差

72 个买点是在**知道后面怎么走**的前提下挑出来的（事后标注）。所以回测里的
「均 +7.85R / 合计 +565R」是这套规则在这段行情里的**上限**，不是未来预期。
可复用的是相对关系：出场规则之间的差距、我选的和没选的之间的差距。
