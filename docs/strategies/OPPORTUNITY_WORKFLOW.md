# 交易机会扫描逻辑说明

本文说明当前 `交易机会` 页面里的几个按钮分别做什么，以及一条交易机会是如何被系统生成的。

## 页面按钮说明

### 扫描全部自选

这是日常最推荐使用的按钮。

它会读取你的自选列表，逐个品种执行以下流程：

1. 同步该品种在当前周期的 K 线数据到本地数据库。
2. 用最新 K 线运行信号检测器。
3. 回看最近一段历史，统计信号组合过去的胜率、样本数、期望 R。
4. 如果最新 K 线也出现了一个历史表现达标的信号组合，就生成一条交易机会。

例如：

- 自选列表里有 `BTC-USD`、`ETH-USD`、`AAPL`
- 周期选择 `4h`
- 点击 `扫描全部自选`

系统会依次扫描：

- `BTC-USD 4h`
- `ETH-USD 4h`
- `AAPL 4h`

扫描完成后，右侧 `历史胜率账本` 会显示对应组合的历史表现；如果有达标机会，左侧会出现机会卡片。

### 扫描选中品种

如果你只想看一个品种，可以在下拉框里选择某个自选品种，然后点击这个按钮。

它只扫描当前选中的品种和周期。

适合这种场景：

- 你只想看 `BTC-USD 4h` 有没有机会
- 不想等待全部自选列表扫描完成
- 想快速更新某一个品种的历史胜率账本

### 回填结果

`回填结果` 不是用来寻找新机会的，它是用来更新“信号发生之后到底表现如何”的。

系统在扫描时会记录最新 K 线触发过的信号事件，例如：

- `BTC-USD 4h` 出现了 `均线趋势`
- `BTC-USD 4h` 出现了 `RSI 极值`

这些信号刚出现时，还不知道后面是涨是跌，所以 outcome 是空的。

等后面已经有足够多的新 K 线之后，点击 `回填结果`，系统会检查这些旧信号后续走势：

- 如果先到止盈，标记为 `win`
- 如果先到止损，标记为 `loss`
- 如果到观察期结束都没触发止盈/止损，标记为 `timeout`

然后系统会用这些真实 forward outcome 更新单个信号的历史表现。

简单说：

- `扫描全部自选 / 扫描选中品种`：发现机会
- `回填结果`：复盘旧信号的后续表现，更新历史账本

### 刷新全部

`刷新全部` 会扫描本地数据库里已有 K 线的所有品种和周期。

它和 `扫描全部自选` 的区别是：

- `扫描全部自选`：以你的自选列表为范围，并且会主动同步 K 线
- `刷新全部`：以本地 `market_candles` 表里已有的数据为范围，不依赖自选列表

一般日常使用 `扫描全部自选` 即可。

`刷新全部` 更适合开发或维护场景，例如：

- 本地数据库里已经有很多历史 K 线
- 想批量刷新所有已缓存品种的历史胜率账本
- 不想只限制在自选列表里

## 一条交易机会是怎么出现的

当前实现可以理解成这条链路：

```text
同步 K 线
  -> 检测技术信号
  -> 判断信号是否共振
  -> 回测该组合历史表现
  -> 读取推荐器阈值
  -> 生成交易计划
  -> 写入机会列表
  -> 图表展示入场/止损/止盈
```

下面按步骤说明。

## 1. 同步 K 线

点击 `扫描全部自选` 或 `扫描选中品种` 时，后端会先同步该品种当前周期的 K 线。

例如：

```text
BTC-USD + 4h
```

会写入本地表：

```text
market_candles
```

这一步保证后面的信号检测和历史统计有数据可用。

## 2. 检测技术信号

系统会把最近 K 线交给信号注册器。

当前 MVP 里已经接入的基础信号包括：

| 内部名称 | 页面显示 | 含义 |
|---|---|---|
| `ema_trend` | 均线趋势 | 快慢均线方向判断趋势 |
| `rsi_extreme` | RSI 极值 | RSI 超买/超卖状态 |
| `pinbar` | Pinbar 反转 | 单根 K 线反转形态 |

每个信号会输出：

- 信号名称
- 方向：做多 / 做空
- 当前周期
- 触发价格
- 信号分数
- 附加指标数据

同时，最新 K 线触发的原始信号会写入：

```text
signal_events
```

这张表用于后续 `回填结果`。

## 3. 判断信号共振

单个信号不一定会生成机会。

当前规则是：

```text
至少 2 个同方向信号同时出现
```

例如：

```text
均线趋势：做多
RSI 极值：做多
```

这两个信号方向一致，就形成一个做多组合。

如果信号方向冲突，例如一个做多、一个做空，则不会通过共振检查。

## 4. 统计组合历史表现

系统会在历史 K 线中查找类似组合过去出现过多少次，并模拟每次之后的表现。

目前使用的是简化 R 模型：

- 默认风险距离约为价格的 `1.5%`
- 先到止损：`-1R`
- 先到止盈：`+2R`
- 到观察期结束还没有触发止盈/止损：按最终价格折算 R，限制在 `-1R` 到 `+2R`

统计后写入：

```text
edge_stats
```

页面右侧的 `历史胜率账本` 就来自这张表。

它会展示：

- 胜率
- 保守胜率
- 样本数
- 期望 R
- 信号组合

## 5. 推荐器阈值过滤

不是所有历史组合都会生成交易机会。

系统会读取推荐器阈值：

```text
recommender_thresholds
```

当前主要看这些条件：

- 样本数是否足够
- 保守胜率是否达标
- 综合分是否达标

综合分大致由三部分组成：

```text
历史保守胜率
信号共振分
样本数可靠性
```

如果组合历史表现太差，或者样本太少，就只会出现在 `历史胜率账本`，不会生成交易机会。

## 6. 生成交易计划

如果组合通过阈值，系统会生成交易计划：

- 入场价：当前收盘价
- 止损：按 ATR/default risk distance 估算
- 止盈：按历史平均 R 或默认 R 倍数估算
- 仓位：默认 `1R`

写入两张表：

```text
opportunities
trade_plans
```

这时左侧会出现一张机会卡片。

## 7. 图表展示

点击机会卡片里的 `查看图表`，会跳转到：

```text
/chart/{symbol}?planId={opportunity_id}
```

图表会拉取这条机会对应的交易计划，并画出三条线：

- 入场
- 止损
- 止盈

## 什么时候看不到交易机会

扫描后没有机会是正常情况，常见原因包括：

1. 最新 K 线没有形成至少 2 个同方向信号。
2. 组合历史样本数太少。
3. 组合历史胜率或保守胜率不达标。
4. 综合分低于最低分阈值。
5. 当前筛选条件太严格，例如只看 `进行中` 或最低分过高。

这时可以先看右侧 `历史胜率账本`。

如果账本里也没有数据，说明该品种/周期还没有足够历史样本，或者还没执行扫描。

## 推荐使用流程

日常使用建议：

1. 先维护好自选列表。
2. 打开 `交易机会` 页面。
3. 选择周期，例如 `4h`。
4. 点击 `扫描全部自选`。
5. 查看左侧是否生成机会。
6. 如果没有机会，看右侧 `历史胜率账本` 判断哪些组合接近可用。
7. 过一段时间有新 K 线后，再点击 `回填结果` 更新旧信号的真实表现。

## 当前 MVP 的边界

当前实现已经打通了核心闭环，但还不是完整生产级交易系统。

已经具备：

- 自选列表扫描
- 单品种扫描
- K 线同步
- 信号检测
- 信号共振
- 历史胜率账本
- 机会生成
- 交易计划
- 图表入场/止损/止盈展示
- 信号结果回填

后续仍可继续增强：

- 更多信号类型
- 更严格的多周期共振
- 更精细的 ATR/SR 止损止盈
- 夜间自动批处理
- Discord 自动推送
- 更完整的实盘 forward audit
