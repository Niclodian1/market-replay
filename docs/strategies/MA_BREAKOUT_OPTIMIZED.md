# 单均线突破策略（优化版 v2）

> 在原版「单均线突破 + 入场 K 线最低点止损」基础上，引入 **5 项入场过滤** 与 **ATR 移动止损 + Chandelier Exit 双重动态出场**，目标：把震荡市假突破挡在门外，让趋势行情利润奔跑。

---

## 一、回测目标

针对多品种历史日线数据，遍历均线参数 **N = 10, 20, …, 200**（步长 10，共 20 个），评估优化后策略的：

- 总收益率、交易次数、最大回撤、胜率
- 平均盈亏比 R、Profit Factor（总盈利 ÷ 总亏损绝对值）
- 跨品种参数稳定性（热力图）

并对比原版单均线策略，验证胜率与盈亏比的改善程度。

---

## 二、策略规则

### 1. 均线定义
- **类型**：收盘价简单移动平均（SMA）
- **周期**：N 日（待优化参数）
- **辅助指标**：
  - 长周期均线 **SMA200**（数据不足 200 日的窗口降级为 SMA120）
  - **ATR(14)**：True Range 的 14 日 Wilder 平滑
  - **成交量 SMA20**

### 2. 入场条件（做多，**6 项必须全部成立**）

| 序号 | 名称 | 条件 |
|------|------|------|
| 1 | 基础突破信号 | `close[t-1] ≤ MA[t-1]` 且 `close[t] > MA[t]` |
| 2 | 长周期趋势过滤 | `close[t] > SMA200[t]`（不足 200 根时用 SMA120） |
| 3 | 均线斜率过滤 | `MA[t] > MA[t-5]`（N 日均线向上） |
| 4 | ATR 突破幅度 | `close[t] - MA[t] ≥ 0.3 × ATR14[t]` |
| 5 | 成交量确认 | `volume[t] ≥ 1.2 × SMA20(volume)[t]`（无成交量数据则**跳过该项**） |
| 6 | 回撤后突破 | 突破前 5 根 K 线 `close` 至少出现一次 `< MA` |

**入场动作**：
- `entry_price = close[t]`（含成本：`eff_entry = close × (1 + 手续费 + 滑点)`）
- `hard_stop = low[t]`（入场 K 线最低点，**全程不变**）
- 记录入场后持仓最高 close 用于 Chandelier
- 初始化 `trailing_atr = close[t] - 3 × ATR14[t]`

### 3. 出场条件（**任一触发即平仓，按以下优先级判断**）

| 优先级 | 名称 | 触发条件 | 平仓价（理论） |
|--------|------|----------|----------------|
| 1 | **保底硬止损** | `low[t] ≤ hard_stop` | `hard_stop` |
| 2 | **ATR 移动止损** | `low[t] ≤ trailing_atr` | `trailing_atr` |
| 3 | **Chandelier Exit** | `low[t] ≤ chandelier` | `chandelier` |

其中：
- `trailing_atr = max(trailing_atr_prev, close[t] - 3 × ATR14[t])` — 仅上调，不下调
- `chandelier = max_close_since_entry - 3 × ATR14[t]`

平仓价均扣单边成本：`eff_exit = 平仓价 × (1 - 手续费 - 滑点)`

> **注**：原版「跌破 N 日均线」出场已被弃用——它在长趋势里出场过早。
> 三种止损方式都基于 ATR / 入场 K 线低点的硬止损，能让赢家奔跑同时严格控亏。

### 4. 信号过滤
- 持仓期间不再发出新入场信号；平仓后下一根 K 线起重新检测。
- 连续同向突破信号只保留第一次。

### 5. 交易方向
仅做多，不允许做空。

### 6. 末日处理
回测结束日仍持仓时，以最后一日收盘价强平，作为一笔完整交易。

---

## 三、交易成本

| 项 | 单边 |
|----|------|
| 手续费 | 0.10% |
| 滑点 | 0.05% |
| **合计单边成本** | **0.15%** |

- 入场有效价：`eff_entry = close × (1 + 0.0015)`
- 出场有效价：`eff_exit  = 触发价 × (1 - 0.0015)`
- 单笔收益率：`ret = eff_exit / eff_entry - 1`

## 五、评估指标

### 单参数指标
| 指标 | 计算 |
|------|------|
| 总收益率 | `(最终资金 - 1) × 100%` |
| 交易次数 | 完整交易笔数（含末日强平） |
| 最大回撤 | `max((历史峰值 - 当日净值) / 历史峰值) × 100%` |
| 胜率 | `单笔收益率 > 0 的笔数 ÷ 总笔数` |
| 平均盈亏比 R | 盈利单的 `(eff_exit - eff_entry) / (eff_entry - hard_stop)` 均值 |
| Profit Factor | `Σ盈利收益率 ÷ Σ\|亏损收益率\|` |
| 最大单笔盈利 | `max(trade_returns) × 100%` |
| 平均盈利 | 盈利单收益率均值 × 100% |

### 跨参数稳定性
- 对每个品种生成 N = 10..200 的 **总收益率 / 最大回撤** 热力图
- 选取**参数平台区**作为稳健最优 N，而非单点最高

---

## 六、最优参数筛选

1. 按 **总收益率** 排名输出 Top 1 与全部 20 档明细。
2. 同时记录 **Profit Factor** 与 **平均盈亏比**，避免选中"高收益伴随极端回撤"的脆弱参数。
3. 热力图视图辅助识别稳健区。
4. ⚠️ **过拟合风险**：本方案不做严格的样本内/外切分（用户已确认放在后续迭代），但通过多品种 + 参数平台区视图降低单点过拟合概率。

## 七、与原版对比预期

| 维度 | 原版 | 优化版 v2 |
|------|------|-----------|
| 入场信号数量 | 多 | 显著减少（5 项过滤） |
| 胜率 | ~20% | 期望 30%+ |
| 平均盈亏比 | 一般 | 显著提升（让利润奔跑） |
| 最大回撤 | 高 | 同参数下应低于原版 |
| 总收益 | 视品种 | 不必更高，但风险调整后收益更优 |
