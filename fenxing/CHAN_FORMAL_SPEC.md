## §0 记号与基本对象

- 原始K线序列 `B = (b_0, b_1, ..., b_{n-1})`，每根
  `b_i = (t_i, o_i, h_i, l_i, c_i, v_i)`，时间严格递增。
- 对K线 `b`，记 `H(b)` 高点、`L(b)` 低点。
- 区间 `[x, y]`（x ≤ y 为价格）与区间 `[i, j]`（i ≤ j 为下标）。
- 两价格区间 `P1=[a1,b1]`, `P2=[a2,b2]` 的**重叠**：`max(a1,a2) < min(b1,b2)`（严格重叠，端点相触不算，见 §6.1 ⚠A）。

## §1 包含关系与K线合并（第62、65课）

**定义 1.1（包含关系）** K线 a 包含 K线 b（或反之），当且仅当
`(H(a) ≥ H(b) ∧ L(a) ≤ L(b)) ∨ (H(b) ≥ H(a) ∧ L(b) ≤ L(a))`。

**定义 1.2（处理方向）** 设合并过程中当前考察对为相邻K线 (p, q)，其前一根已冻结K线为 r：
- 若 `H(r) < H(p)` → 方向为**上**；
- 若 `H(r) > H(p)` → 方向为**下**；
- 若 `H(r) = H(p)` ⚠A：原文未规定。裁决：相等→向上（与代码 `append_merged_bar` 的 `H(r) >= H(p)` 判定一致），序列开头不足三根时同样取相等→向上。

**定义 1.3（合并运算）** 方向为上时，合并结果 `m`：
`H(m)=max(H(p),H(q))`，`L(m)=max(L(p),L(q))`；
方向为下时：`H(m)=min(H(p),H(q))`，`L(m)=min(L(p),L(q))`。
`O(m)` 取两根中先出现者的开盘，`C(m)` 取后出现者的收盘，`t` 取先者的开始时间，成交量累加。

**定义 1.4（合并过程）** 从左到右扫描：新K线入队后，只要队尾两根存在包含关系即按 1.2–1.3 合并为一个元素，重复直到无包含；继续下一根。输出**合并K线序列** `M = (m_0, ..., m_{k-1})`，每个 `m_j` 携带其覆盖的原始K线下标闭区间 `[s_j, e_j]`。

**性质（原文第65课"处理后的K线无包含关系"）** 对任意相邻 `m_j, m_{j+1}`：`H(m_j) ≠ H(m_{j+1})` 且 `L(m_j) ≠ L(m_{j+1])` 至少一项严格成立，且不存在包含。

## §2 分型（第62课）

**定义 2.1（顶分型）** 合并K线三元组 `(m_{i-1}, m_i, m_{i+1})` 构成顶分型，当且仅当
`H(m_i) > H(m_{i-1}) ∧ H(m_i) > H(m_{i+1}) ∧ L(m_i) > L(m_{i-1}) ∧ L(m_i) > L(m_{i+1})`
（中间K线为三者的**双向严格极值**——高、低点同时最高）。

**定义 2.2（底分型）** 对称：
`L(m_i) < L(m_{i-1]) ∧ L(m_i) < L(m_{i+1}) ∧ H(m_i) < H(m_{i-1}) ∧ H(m_i) < H(m_{i+1})`。

⚠B（分型有效性）：原文只要求上述几何条件，未要求后续K线确认。本仓库的"收盘确认"（其后 W 根原始K线内任一收盘价突破中K线极值，W=3）是**工程增强**，不是原文定义。凡声称"原文口径"的回测须以 2.1/2.2 为准，确认规则单独作为开关。

**定义 2.3（分型定位）** 顶分型的价格 = `max{H(b_t) : t ∈ [s_i, e_i]}`，其原始bar为取该最大值的 t；底分型对称。

## §3 笔（第62、65、67课）

**定义 3.1（笔的候选端点序列）** 将 M 上识别出的顶、底分型按位置排序，施加**交替约束**：序列中相邻元素必须异类；连续同类时保留价格更极端者（顶取更高者，底取更低者）。输出严格交替序列 `F = (f_0, f_1, ...)`，`f_j = (pos_j ∈ M下标, kind_j ∈ {T,B}, price_j)`。

⚠C（笔的成笔标准，原文两套口径并存）：
- **老笔**（第62课）：相邻顶底分型之间，合并K线 ≥ 5 根（即 `pos差 ≥ 5`，中间至少4根独立K线），且顶分型最高点高于底分型区间、底分型最低点低于顶分型区间。
- **新笔**（第67课，对老笔的放宽）：顶底之间（原始口径按原始K线）≥ 5 根无包含K线；等价于合并K线间距 ≥ 4。
- 本仓库取新笔：`pos_j+1 − pos_j ≥ 4`（合并K线跨度，含端点为5）。
- ⚠C 裁决：两套口径不可混用于同一分析链；系统参数 `MIN_STROKE_SPAN` 显式声明所用口径。
- **双口径并行实现（2026-08）**：新笔为信号主链（买卖点/回测口径）；老笔作为对照链，
  以同一因果引擎、同一确认时序独立推导 线段→中枢→买卖点 全链，输出 `old*` 系列
  （`oldSegmentsRaw/Merged`、`oldPivotsStroke*/Segment*`、`oldBuyPointsStroke*/Segment*` 等）。
  前端「笔口径」开关整链切换显示。两链共享分型层（同一条顶底交替序列），仅成笔标准不同；
  老笔链的买卖点同样满足「已发出的点不事后删除」，故其数量 ≥ 同口径批量终态扫描的结果。

**定义 3.2（笔的构建算法）** 依序扫描 F，维护开放端点 `e`：
1. 新分型 f 与 e 同类：若 f 更极端，则 f 替换 e；同时若已存在以 e 为终点的笔，该笔终点**延伸**至 f（不删除，保证笔序列首尾相接）。
2. f 与 e 异类：若满足 3.1 距离与价格条件 → 成笔（e → f），e := f；否则**丢弃 f**。

**定义 3.3（笔对象）** 上升笔 `S = (底分型 → 顶分型)`：`s_price = L(底)`, `e_price = H(顶)`, `dir = +1`；下降笔对称 `dir = −1`。笔的K线区间 = 端点分型定位bar之间的原始K线闭区间。

**性质**：笔序列严格交替方向、首尾相接（前笔终点分型 = 后笔起点分型）。

## §4 线段（第65、67、71课）

线段由**至少 3 笔**构成，且前 3 笔必须有重叠区间。

**定义 4.1（特征序列）** 对方向为 d 的线段，其特征序列 = 该线段内所有**反向笔**（dir = −d）按序构成的K线序列，每根取该反向笔的 `[low, high]`。

**定义 4.2（特征序列包含处理）** 对特征序列做 §1 的包含合并，但合并方向**按线段方向**：
- 线段向上（d=+1）：取高高、高低（`H=max`, `L=max`）；
- 线段向下（d=−1）：取低高、低低（`H=min`, `L=min`）。
（理由：向上线段考察的是"回撤力度"，合并应保留更强的回撤形态。）

**定义 4.3（特征序列分型）** 处理后的特征序列中，连续三元组 `(a, b, c)` 构成**顶分型**（对向上线段）：`H(b) > H(a) ∧ H(b) > H(c) ∧ L(b) > L(a) ∧ L(b) > L(c)`；向下线段对称看底分型。（双向极值口径，与 §2 一致。）

**定义 4.4（缺口）** 特征序列分型的第一、二元素 `a, b` 之间存在缺口，当且仅当 `L(a) > H(b) ∨ L(b) > H(a)`（两区间无重叠）。

**定义 4.5（线段终结判定）** 对以笔 j 开始、方向 d 的线段，扫描后续笔：
- 每遇反向笔加入特征序列并做 4.2 合并；
- 出现 4.3 分型时：
  - **第一种情况**（4.4 判无缺口）：线段在该分型的中间元素处终结，线段终点 = 该中间元素对应反向笔的**前一同向笔**端点（线段由奇数笔构成）。
  - **第二种情况**（有缺口）：需**反向验证**——从分型中间元素之后构建新方向（−d）的特征序列（取与 −d 同向的笔），若该序列经 4.2 合并后出现 4.3 分型（新方向的特征序列分型），则原线段确认终结于同一位置；否则分型无效，原线段延续。
- 扫描至笔序列末端无终结 → 末线段为**在途**（`complete = false`），其延伸权保留。

**性质**：线段方向 = 其首笔方向；完整线段由奇数笔构成；相邻线段方向相反、首尾相接。

⚠D（第二种情况的递归深度）：原文对"反向特征序列的分型"是否再做缺口讨论未展开。本规范取一层验证（不递归），与第71课图示一致。

## §5 级别（第17、20、21课）

**定义 5.1（递归级别）** 缠论的级别不是时间周期，而是构造层级：
`级别 0`：分型 → 笔（基础构件）；
`级别 k+1`：由级别 k 的走势类型（§7）作为构件构造的走势类型。
即：笔 → 线段（由笔构成）→ 由线段构成的中枢/走势 → 由该级走势构成的更高级中枢/走势……

**定义 5.2（同构近似，工程声明）** 实践中以时间周期（1H/4H/1D）各自独立运行同一套 §1–§4 流水线来近似 5.1 的递归级别。该近似的合法域：次级别周期 ≈ 大级别的 1/4 ~ 1/6（1D:4H ≈ 6, 4H:1H = 4）。近似失效情形：大级别一笔在次级别上未形成完整走势类型（无中枢），此时次级别"一买"不存在是**级别失配**而非联动失败（见 §12）。

## §6 中枢（第18、20、21、22课）

**定义 6.1（中枢）** 设 `L = (l_0, l_1, ...)` 为某一级别的连续走势单元（线段口径或笔口径，同一分析内必须统一），连续三个单元 `(a, b, c)` 的价格区间两两重叠，即
`ZD = max(L(a), L(b), L(c))`，`ZG = min(H(a), H(b), H(c))`，且 `ZD < ZG`，
则 `[ZD, ZG]` 构成一个**中枢**。记：
- `GG = max(H(a), H(b), H(c))`（震荡最高），`DD = min(L(a), L(b), L(c))`（震荡最低）；
- 中枢的时间区间 = `[a 的起始bar, c 的结束bar]`（延伸时更新，见 6.2）。

⚠A（重叠是否含端点）：原文图示均按区间相交（≤）处理。本规范取严格 `<`（`ZD < ZG` 才成立），端点相触（`ZD = ZG`）不算中枢——与"至少三个次级别走势重叠"的语义一致，且避免退化区间。

**定义 6.2（中枢延伸）** 中枢成立后，其后的单元 `l_k` 逐个考察：
- 若 `L(l_k) ≤ ZG ∧ H(l_k) ≥ ZD`（与 [ZD,ZG] 有重叠）→ 中枢**延伸**：`level_end := k`，`GG := max(GG, H(l_k))`，`DD := min(DD, L(l_k))`。
- 若无重叠 → 该单元为**离开段**，中枢在该单元之前结束。

⚠E（离开后的回拉，原文两解）：原文第20课"中枢延伸"与第22课图示存在两解：
- 口径 α（现行默认）：任一单元与 [ZD,ZG] 无重叠 → 中枢**立即**结束。
- 口径 β（原文回拉口径）：无重叠单元视为离开段；若其后某单元重新与 [ZD,ZG] 重叠（回拉）→ 中枢延伸至该单元；若始终不回拉 → 中枢止于最后一个重叠单元。依据："任何对中枢的回拉均构成中枢延伸"。
- 两口径互斥，作为参数 `pullback_ext ∈ {α, β}` 显式声明；A/B 实验决定采用。

**定义 6.3（中枢的新生）** 中枢结束后，若离开段方向上的后续走势形成**新的、区间不重叠的**中枢（向上离开：新中枢 ZD ≥ 旧中枢 ZG；向下离开：新中枢 ZG ≤ 旧中枢 ZD）→ 称中枢**新生**，构成趋势的构件（§7）。

⚠F（中枢扩展/扩张）：原文第22课提到中枢"扩展"（两个同向中枢通过一个更大级别的中枢连接），其精确定义原文未给出可操作判据。本规范**暂不形式化扩展**，凡涉及跨中枢连接的结构一律用"中枢序列 + 区间关系"显式描述，不使用"扩展"概念。

**定义 6.4（中枢链）** 中枢序列 `(P_0, P_1, ..., P_m)` 称为**下降链**，若 `DD(P_{j-1}) > DD(P_j)` 对所有 j 成立（逐级下移，允许区间重叠——覆盖层层嵌套的下跌）；**上升链**对称（`GG(P_{j-1}) < GG(P_j)`）。

⚠G（链的严格性）：原文对"趋势"要求后中枢区间完全低于/高于前中枢（第17课：同级别前后中枢不能有任何重叠）。定义 6.4 的"仅 DD/GG 递降"是**放宽口径**（为覆盖嵌套下跌）。严格口径：`ZG(P_{j-1}) > ZD(P_j)`（下降链，区间无重叠）。两口径作为参数声明；一买/一卖判定在两口径下的差异须回测对照。
**补注（与 ⚠E 的区分，2026-08 核验）**：⚠G 的"链口径"（哪些下跌构成趋势语境）与 ⚠E 的"延伸口径"（中枢何时结束）是**两个独立自由度**，勿混淆。⚠E 的回拉口径（pullback_ext=β）已被本仓库数据证伪（tutorial.html 第10章第2条：放宽版产生 57 段怪物中枢），保持 α；**⚠G 已于 2026-08 由用户裁决采用严格无重叠口径（原文口径），放宽的 DD 递降链退役（见 §9.1 修订记录）**。

## §7 走势类型（第16、17、20课）

**定义 7.1（盘整）** 某级别走势只包含**一个**中枢。
形式化：该级别单元序列生成的中枢序列长度 = 1，且首尾单元分别构成进入/离开段。

**定义 7.2（趋势）** 包含**至少两个**同向新生中枢（6.3 意义下区间无重叠）的走势：
- 上升趋势：中枢序列为 6.4 严格口径上升链（后中枢 ZD ≥ 前中枢 ZG）；
- 下降趋势：对称。

**定义 7.3（走势的完成）** 走势必完美（第17课）：一个走势类型以其**离开段被次级别走势终结**为完成。工程判据：离开段端点的分型被收盘确认（§2），或离开段本身作为线段被 §4 终结。

**定义 7.4（走势级别归属）** 一个走势类型的级别 = 其构成单元的级别 + 1（5.1 递归）。同构近似下，"1D 级别走势" ≈ 1D 图上由线段构成的中枢/趋势。

## §8 背驰（第15、24、25、27、29课）

**定义 8.1（比较段）** 趋势背驰的比较对象是**同向、同级别、围绕同一中枢链**的两段：
- `A 段`（基准）：进入最后一个中枢的同向段（**原文口径，enter**）；或中枢链内同向段中"力度"最大者（**工程口径，strongest**）。
- `C 段`（考察段）：离开最后一个中枢的同向段，且其端点价格**创新极值**（下降：低于链上前一中枢 DD；上升：高于链上前一中枢 GG）——否则不构成趋势背驰语境（该低/高点属二买/二卖结构）。
- 两口径 `a_mode ∈ {enter, strongest}` 显式声明，不可混用。

**定义 8.2（力度）** ⚠H：原文定义"走势力度"未给公式，仅说"可用 MACD 辅助"。本规范取 MACD 柱面积作为力度的**可计算代理**：
- `力度(段, 方向) = Σ |histogram(t)|`，t 遍历该段K线区间内符号与段方向一致的柱（下降段取负柱，上升段取正柱）；
- MACD：`DIFF = EMA12 − EMA26`，`DEA = EMA9(DIFF)`，`histogram = DIFF − DEA`，EMA 为标准递归 `E_t = α·x_t + (1−α)·E_{t−1}`，`α = 2/(N+1)`。
- 该代理的合法性依赖原文"背驰 = 力度衰竭"的定性判断，**面积比是判据的参数化**，不是原文定义本身。

**定义 8.3（趋势背驰）** 在 8.1 语境（存在 6.4 中枢链 + C 段创新极值）下：
`力度(C) < θ · 力度(A)`，θ ∈ (0,1]（本系统 θ = 0.9）→ C 段发生**趋势背驰**。

**定义 8.4（盘整背驰）** ⚠I（原文第25课，本系统尚未实现）：离开**单个**中枢的段与进入该中枢的同向段比较，`力度(C) < θ · 力度(A)` → 盘整背驰。与 8.3 的区别仅在于语境是单中枢（盘整，7.1）而非中枢链（趋势，7.2）。判据形式与 8.3 完全同构。

**定义 8.5（区间套，第27课）** 大级别背驰段内部，逐级下钻：大级别 C 段（原始K线区间 `[s, e]`）内部，次级别上存在同向背驰段 C'，其区间 `[s', e'] ⊆ [s, e]`；递归至最小级别。**结构同一性判据**：区间嵌套，而非时间接近。

**定义 8.6（背驰的时效）** 背驰判断只在其 C 段端点被分型确认（§2/§3）后成立；端点延伸（3.2 同类更极端替换）会使既有背驰判定**失效**并重算——背驰是状态，不是事件。

## §9 三类买卖点（第18、20、21课）

以下以买点陈述，卖点全部对称（方向反转、低换高）。所有点均以**端点分型的收盘确认bar**为信号时点 confirmedT，以端点极值价为参考价。

**定义 9.1（第一类买点）** 存在下降中枢链（6.4）`P_0 > P_1 > ... > P_m`，离开 `P_m` 的向下段 C 满足 8.1/8.3（创新低 + 趋势背驰）→ C 的端点为一买。
- 时效约束（工程）：confirmedT 距端点超过 Q 根K线（本系统 Q=8）则放弃该信号（不再是可交易入场）。
- 不删除条款：一买发出后，即使其后出现更低中枢（背驰失败），该点保留计入统计，不做事后清洗。

**修订（2026-08，用户定稿 · 原文严格口径）**：
- **中枢链**：采用 ⚠G 的严格无重叠口径——相邻前中枢下沿 `ZD(P_{j-1}) > ZG(P_j)`；放宽的 DD 递降链退役。
- **C 段判据计算化**：C = 中枢内（含其后一根单元）向下跌破 **A 段低点** 的最低向下笔；突破进入段低点即视为离开段，不再对照链前中枢 DD。
- **力度度量**：同向 MACD 柱**单柱均值**（总面积 ÷ 同向柱根数，消除段长偏置）；`均值(C)/均值(A) < θ' = 0.75`（`TREND_DIV_RATIO`）判背驰；按 `<0.25 强 / <0.5 中` 分三档展示。
- **二买连带抑制**：父一买候选被 Q=8 丢弃时，其派生的二买一并抑制（二买的定义前提是一买成立）。

**定义 9.2（第二类买点）** 一买端点之后，单元序列出现 `上升段 R` + `下降段 D`，且 `L(D) > L(一买端点)`（不创新低）→ D 的端点为二买。
- 理论保证（第20课）：二买不低于一买由次级别第一类卖点结构保证。
- ⚠J（次级别对应物）：原文中二买的次级别确认物是**盘整背驰**（8.4），非次级别一买。联动标注不得对二买使用次级别趋势背驰判据（见 §12.3）。

**定义 9.3（第三类买点）** 某中枢 P 被向上**离开**（离开段 `H > ZG(P)`）后，其后的回抽段 D 满足 `L(D) ≥ ZG(P)`（不回中枢）→ D 的端点为三买。
- 若离开段本身即为向下回抽（离开与回抽合一），取 `L(离开段) ≥ ZG(P)`。
- 理论意义：三买确认中枢**新生**（6.3），新趋势开始；其后的赢法是持有至该新趋势的一卖（第20课）。

**定义 9.4（卖点对称表）**
- 一卖：上升中枢链 + 向上离开段创新高 + 顶背驰（8.3 方向反转）。
- 二卖：一卖后 `下降段 + 上升段`，反弹高点 `H(R) < H(一卖端点)`。
- 三卖：中枢被向下离开后回抽段 `H(D) ≤ ZD(P)`。

**定义 9.5（信号因果性总则）** 任何买卖点的判定只允许使用 confirmedT 及之前的信息：
包含合并只修改队尾未冻结元素；分型在其右邻合并K冻结后判定；笔由已确认分型构成；中枢/背驰由已构成笔构成。违反者为未来函数。

## §10 多级别联动（第26、27、43课）

**定义 10.1（引发关系，第43课）** 大级别走势的转折点，必然由次级别走势的第一类买卖点引发。形式化：大级别买点端点的原始K线区间 `[s, e]` 内，次级别存在同向一买的 C 段区间 `[s', e']`，且 **`[s', e'] ⊆ [s, e]`（区间嵌套）**。

⚠K（时间窗近似及其缺陷）：工程实现常退化为时间窗匹配 `|t_big − t_sub| ≤ W`。缺陷：(1) 端点对端点，不保证是同一段走势的两级投影；(2) 对称窗口放行"次级别滞后于大级别"的伪联动（因果上次级别信号应不晚于大级别确认）；(3) 次级别以盘整背驰形式出现时漏检（8.4 未实现）。规范口径取 10.1 的嵌套判据 + 因果不对称容差：`s' ≥ s − δ, e' ≤ e + δ`，δ 为次级别确认延迟（≤1 根次级别K线）。

**定义 10.2（上级别语境）** 小级别买卖点落于上级别某中枢的时间区间内 → 该点具有"上级别中枢内"语境（用于区分中枢震荡操作与趋势操作，第25课）。

**定义 10.3（联动判据按点型分派）**
- 大级别一买/一卖 ↔ 次级别一买/一卖（10.1）。
- 大级别二买/二卖 ↔ 次级别盘整背驰（8.4，实现后生效）。
- 大级别三买/三卖 ↔ 次级别回抽不回中枢（9.3 的结构判据，非背驰判据）。
- 禁止跨点型混用判据（历史教训：联动率 二买5%/三买1% 即混用所致）。

## §14 次级别：原文全部陈述的提取与形式化

> 原文中"次级别"不是单一定义，而是**一组不同语境下的构造关系**。本节逐条提取、
> 各自形式化，并说明它们之间的推导关系。这是全规范中最容易被"一句话糊过去"的概念，
> 单独立节。

### 14.1 构造性定义（第17课）—— 次级别是中枢的构成单元

原文：某级别中枢由**次级别的走势类型**重叠构成；走势的级别由构成它的次级别走势自组而成。

形式化：§6.1 中枢定义中的单元 `l_i` **必须**是次级别的完整走势类型（7.1/7.2，即含自身中枢的盘整或趋势），而非任意笔/线段。
- 推论 1：判断某级别走势是否完成（7.3），判据落在次级别走势的完成上（"走势终完美"）。
- 推论 2：级别链是严格递归的：`级别k走势 ⊃ 级别k中枢 ⊃ 3个级别k−1走势`。

### 14.2 最低级别的退化（第35课）—— 笔/线段作为次级别的原文依据

原文：1分钟以下不再细分，1分钟中枢由**线段**构成；最低级别处，"次级别走势类型"退化为线段（乃至笔）。

形式化：`Sub(级别0走势) = 线段`；`Sub(线段) = 笔`。
- **这是工程近似（5.2）的原文合法性来源**：在最低级别，用笔/线段充当"次级别走势类型"是原文自己的退化处理，不是发明。
- 边界声明：该退化**只对最低级别合法**。对更高级别（如 1D），严格口径下次级别仍是完整走势类型（14.1），笔/线段代理是近似，须声明。

### 14.3 二买与次级别（第20课）—— 次级别的第一类卖点保证二买

原文：一买后次级别上涨，再次次级别回抽不创新低即二买；二买之所以不低于一买，由**次级别的第一类卖点**（该次级别上涨的趋势背驰）结构保证。

形式化：`二买成立 ⇔ 存在次级别下跌段 D，L(D) > L(一买)`；其理论保障是：该次级别上涨以一卖（次级别趋势背驰）终结，故回抽不破。
- 由此得出联动判据 10.3 的第二行：大级别二买 ↔ 次级别一卖/盘整背驰（注意是**卖**侧结构保证**买**点成立，方向交叉，勿写成次级别一买）。

### 14.4 三买与次级别（第21课）—— 次级别回抽的几何判据

原文：中枢向上离开后，次级别回抽不回中枢区间，即三买。

形式化：`三买 ⇔ 次级别回抽段 D 满足 L(D) ≥ ZG(P)`（9.3）。此处次级别角色是**几何构件**（回抽段），无背驰要求——与 14.3 的背驰判据性质不同。

### 14.5 中枢延伸与次级别（第22课）—— 震荡由次级别走势构成

原文：中枢延伸中，每次次级别离开又返回，构成中枢震荡；震荡的每个往返是一个次级别走势类型。

形式化：6.2 延伸判据中的单元 `l_k` 与 [ZD, ZG] 的重叠检验，其对象是次级别走势；中枢的震荡时长 = 次级别走势的个数。
- 推论：⚠E 的回拉口径（pullback_ext=β）中"离开段"与"回拉段"都必须是次级别完整走势，工程上以本级别线段代理。

### 14.6 盘整背驰与次级别（第25课）—— 中枢震荡的操作单元

原文：中枢震荡中，次级别的离开段与进入段可做力度比较（盘整背驰），用于震荡操作的高抛低吸。

形式化：8.4。次级别角色：**比较对象的提供者**——盘整背驰的比较双方是围绕同一中枢的次级别（代理：本级别线段/笔）同向段。

### 14.7 区间套与次级别（第27课）—— 背驰段的逐级下钻

原文：大级别背驰段内部，次级别上必有对应的背驰段；逐级下钻可精确定位转折点。

形式化：8.5 的区间嵌套 `[s', e'] ⊆ [s, e]`。次级别角色：**同一走势的低分辨率投影**。这是"次级别"最严格的使用语境——要求结构同一性，非时间相关。

### 14.8 引发关系（第43课）—— 转折的必要结构

原文：任何大级别的转折，都由小级别的第一类买卖点引发。

形式化：10.1。与 14.7 的关系：区间套是"定位工具"（几何），引发关系是"结构必然性"（因果）。两者共同构成 10.3 判据一行的理论依据。

### 14.9 表里关系（第83课）—— 笔与线段的操作节奏

原文：本级别（线段）与次级别（笔）构成"表里"：次级别笔的状态（向上/向下、是否延伸）决定本级别线段的操作节奏。

形式化：设本级别线段方向 d、次级别当前笔方向 p：
- `p = d`：表里同向，趋势状态（持仓/顺势）；
- `p = −d`：表里背离，回撤状态（次级别笔终结分型确认时是本级别的加减仓时点）。
- 次级别角色：**操作时钟**——本级别信号的确切时点由次级别构件的分型确认给出（这正是 9.5 因果总则的结构来源）。

### 14.10 多义性与次级别（第33课）—— 划分不唯一性

原文：同一走势可按不同方式组合成不同级别的走势类型（多义性），次级别划分不唯一。

形式化含义：线段划分（§4）在边界情形存在多解时，不同解导致不同的中枢/买卖点。工程裁决：**固定一套确定性划分规则（本规范 §4 的特征序列法是确定性的）并全程一致**，多义性不作为自由度引入。此条是"为什么必须用算法而非人工划线"的原文依据。

### 14.11 汇总：次级别的四种角色

| 角色 | 语境 | 课号 | 形式化位置 |
|------|------|------|-----------|
| 构造单元 | 中枢/走势由次级别走势重叠构成 | 17, 35 | 6.1, 14.1, 14.2 |
| 结构保证 | 二买由次级别一卖保证；转折由次级别一买引发 | 20, 43 | 14.3, 14.8 |
| 几何构件 | 三买的回抽段；延伸的震荡往返 | 21, 22 | 14.4, 14.5 |
| 定位投影/操作时钟 | 区间套下钻；表里节奏 | 27, 83 | 14.7, 14.9 |

**核心结论**：原文的"次级别"在不同课里分别充当构造单元、保证结构、几何构件、投影与时钟五种角色，**没有任何一处把它定义为"小一个数量级的时间周期"**。周期近似（5.2）是工程代理，其合法性边界由 14.2（最低级别退化）与 14.1（高级别须完整走势）共同界定。

## §15 可量化性评估：体系各部分的可计算性分级

> 对本规范覆盖的全部原文概念，按"能否无失真地转为可计算判据"分四级评估。
> 分级标准：
> **L1 完全可量化** — 原文定义本身即几何/逻辑条件，形式化零信息损失；
> **L2 可量化但需代理** — 原文是定性概念，须引入原文之外的度量（代理变量），
> 量化结果依赖代理质量，属"参数化近似"而非"定义本身"；
> **L3 部分可量化** — 概念的骨架可计算，但核心环节存在原文未规定的自由度或多解性，
> 只能在固定裁决下量化，且结论对裁决敏感；
> **L4 原文不可量化** — 原文未给出（或无法给出）可操作判据，任何形式化都是发明而非整理。

### 15.1 结论与工程含义

1. **体系的骨架（L1部分）可以无损实现**——事实上 `fractals.py` + `chanlun.py` 的分型/笔/线段/中枢层已经做到。这一层的分歧只来自 §12 清单中已参数化的自由度。
2. **体系的信号层（买卖点+背驰）整体处于 L2**：结构判定是 L1 的，但触发判据全部经过 MACD 面积这个代理。因此任何"缠论信号"的回测结果，严格说是"**MACD-面积-参数化的缠论信号**"的结果，θ 和 a_mode 的选择与缠论本身的正确性是两个问题。
3. **最值得投入的量化改进在把 L3 降级**：盘整背驰(⚠I)、嵌套联动(⚠K)、链口径(⚠G) 三项都有明确的实现路径，完成后信号层的截断样本问题（27%联动覆盖率）才可归因。
4. **L4 部分应显式排除出回测叙事**：凡报告或文档中出现依赖 ⚠F/仓位/共振权重的结论，必须标注"工程外推，非缠论原文"，避免理论包装。
