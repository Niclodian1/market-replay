# MA A 策略 ATR 入场实验

这个目录用于回答一个单一问题：在保持 MA A 策略其余规则不变时，使用上一根
`Wilder ATR(14)` 对入场阳线实体做标准化，哪个全局阈值最稳健。

## 固定规则

- MA：30 / 60 / 99 / 120。
- 基础信号：前收盘不高于前 MA，当前收盘高于当前 MA。
- 原版过滤：`close / open - 1 > 3%`。
- ATR 过滤：`(close - open) / ATR14[t-1] >= K`。
- 初始止损、4% 后下一根起保本、低于 MA 3% 出场、单边 0.15% 成本均保持不变。
- 为了只测入场过滤，本实验继续按信号 K 线收盘成交；“下一根开盘成交”留给后续独立实验。

## 防止用测试集选参数

每个品种/周期按时间切分：前 70% 为开发样本，最后 30% 为留出样本。参数只根据
开发样本选择，留出样本只用于最终验证。跨越切分点仍未结束的开发样本交易不会计入
任一侧。

实验同时输出两种执行口径：

- `single`：同一品种、周期、MA 同时只持有一笔，更接近可执行账户。
- `legacy_parallel`：复现原 A 策略允许重叠交易、每笔独立计收益的逻辑。

推荐参数由两种口径在开发样本中的等权稳健排名共同决定。排名使用中位年化表现、
中位单笔期望、Profit Factor、盈利面板占比、回撤和有效面板覆盖率，不使用留出样本。
为了避免选择单点尖峰，最终选择标准是当前阈值及左右各 0.1 ATR 的三点邻域平均分。

## 目录结构

- `run_experiment.py`：完整、可重复运行的实验。
- `data/`：运行时保存的标准化 OHLCV 数据快照与清单。
- `results/`：全量指标、汇总、推荐 JSON 和图表。
- `RESULTS.md`：运行后自动生成的中文结论。

运行：

```bash
MPLCONFIGDIR=/tmp/ma_a_atr_mpl python3 experiments/ma_a_atr_entry/run_experiment.py --refresh-data
```

不带 `--refresh-data` 时优先复用目录内数据快照。
